# Roadmap

Aikito is under active development. See the root [README](../README.md) for the
current release status and installation method.

Planned areas include:

- packaged CLI distribution for independent upgrades;
- improved workspace health and diagnostics;
- broader Agent capability coverage;
- a companion browser conversation capture workflow that distills AI chats
  into focused local Markdown notes.

Roadmap items describe direction, not release commitments. Stable behavior is
documented in the root [README](../README.md), the [CLI
reference](cli-reference.md), and command help for the installed version.
