# Roadmap

Aikito is under active development. See the root [README](https://github.com/lsaint/aikito#readme) for the
current release status and installation method.

## Ongoing

- Keep pace with Agent configuration and runtime changes, and add support for
  more Agents when the integration can be tested and maintained reliably.
- Make resource workflows more consistent across instructions, skills, MCP
  servers, subagents, inbox notes, and durable memory.
- Expand the public Python API with reusable workspace operations, following
  the `Project.prepare()` model, so integrations can use Aikito's domain logic
  without invoking CLI commands.
- Improve first-run setup, adoption, and multi-machine workspace portability
  without weakening Aikito's local-first, plain-file model.

These areas describe direction, not release commitments. Stable behavior is
documented in the root [README](https://github.com/lsaint/aikito#readme), the
[CLI reference](cli-reference.md), and command help for the installed version.
