Design principles

Simple primitives. Strong ownership.

Git-managed

Your workspace has history. Decisions and memory can be reviewed and corrected.

Agent-neutral

Your project context does not belong to a single vendor or coding agent.

Local-first

Plain files in normal paths. No daemon, no database, no account.

Inspectable

See what every agent consumes, preview changes, and spot conflicts before syncing.

Start in two minutes

Take control of the setup you already use.

Adopt supported Agent configuration, then synchronize it from one source of truth.
Starting from scratch? Adoption is simply a no-op.
